- **🍜 40+ 全景剧集片库**：
  - **爆笑下饭**：《迷宫饭》《男子高中生的日常》《齐木楠雄的灾难》《间谍过家家》《坂本大佬》《辉夜大小姐》《碧蓝之海》《极主夫道》《游戏三人娘》《小林家的龙女仆》...
  - **治愈公路**：《葬送的芙莉莲》《摇曳露营△》《夏目友人帐》《孤独摇滚！》《白箱》《紫罗兰永恒花园》《强风吹拂》《比宇宙更远的地方》《虫师》《CLANNAD》...
  - **高能神作**：《死亡笔记》《进击的巨人》《灵能百分百》《一拳超人》《钢之炼金术师FA》《排球少年！！》《命运石之门》《咒术回战》《鬼灭之刃》...
  - **经典下饭神剧**：《武林外传》《生活大爆炸》《摩登家庭》《请回答1988》《孤独的美食家》《父母爱情》《家有儿女》《IT狂人》...
- **🎯 场景速配模式**：一键切换【🍜 下饭速配 (20min)】、【🌙 睡前催眠】、【⚔️ 周末通宵】、【📺 国产/经典神剧】。
- **📑 自定义片单 & 收藏库**：支持随时录入自己的想看清单，标记已看/未看，支持单独抽取自选片库（基于 LocalStorage 持久化）。
- **🔍 影视直达聚合**：抽取到的剧集一键直达【📺 B站搜索】、【⭐ 豆瓣评分】、【🔍 影视搜索】。
- **🎧 原生 6 轨 Lo-Fi 白噪音合成器**：
  - 窗外细雨 (Rain)、温暖营火 (Fire)、海浪潮汐 (Ocean)、林间清风 (Wind)、夏夜微鸣 (Night)、街角咖啡 (Cafe)。
  - 内置专注码字、深度助眠、舒适咖啡 3 套一键混音预设。
  - 内置抽奖哔哔与中奖 Web Audio 芯片级音效。
- **🌿 4-4-4 放松深呼引导**：光晕动效引导深呼吸。
- **🎨 高饱和旅行插画风**：青绿基调、暖橙明黄点缀、立体阴影边框。

单文件纯前端，零外部 npm 依赖，双击即开：

```bash

cd chill-companion
open index.html
```
