## ✨ 核心特性

- **🍜 下饭/休闲番剧随机器**：预置《迷宫饭》《葬送的芙莉莲》《男子高中生的日常》《齐木楠雄》等 12 部高分下饭/治愈神番，支持分类筛选与一键抽取。
- **🎧 Web Audio 原生白噪音合成器**：零外部音频依赖，直接调用浏览器底层 Web Audio API 原生合成窗外细雨、温暖营火、林间清风与咖啡馆粉红噪音，支持多轨自由混音与专注/助眠预设。
- **📝 本地随手记便签**：基于 LocalStorage 实现无感实时保存，断网离线可用。
- **🎨 高饱和清新旅行海报插画风**：青绿为主底色，明黄/暖橙/湖蓝/紫分区，深色边框与立体阴影，规整网格设计。
- **📦 零外部依赖**：单文件纯前端，双击即开，极速加载。

## 💻 本地运行

无需安装任何运行时或依赖，克隆后直接用浏览器打开：

```bash
git clone https://github.com/shali10/chill-companion.git
cd chill-companion
open index.html # 或在浏览器中双击 index.html
```
